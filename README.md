# SkyNet Genesis OS

### Intelligence. Security. Independence.

An independent Polish Linux distribution founded
by **Marcin Sczesny** in 2026.

## Project objectives

- Debian 13 Trixie foundation
- Local artificial intelligence
- Qwen3 AI integration
- Cybersecurity and privacy
- System hardening
- Broad hardware compatibility
- Custom SkyNet graphical environment
- AMD64 architecture

## Founder

**Marcin Sczesny**

Country of origin: Poland

Founded: 2026

## Development status

Experimental development.
Physical hardware compatibility and installation
are currently undergoing validation.
