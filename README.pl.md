# SkyNet Genesis OS

Niezalezna polska dystrybucja systemu Linux,
zalozona przez Marcina Sczesnego w 2026 roku.

## Zalozenia projektu

- Debian 13 Trixie
- Lokalna sztuczna inteligencja
- Integracja Qwen3
- Bezpieczenstwo i prywatnosc
- Autorski interfejs graficzny
- Szeroka kompatybilnosc sprzetowa

## Status

System znajduje sie w fazie rozwoju i testowania.
